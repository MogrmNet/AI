    المشكلةThe problem

    كشف وجود الحركة في الغرف عادةً يعتمد على كاميرات (حساسية خصوصية) أو حساسات مخصصة (تغطية محدودة بخط الرؤية). نبحث في بديل يعتمد على قياسات قناة لاسلكية موجودة أصلًا في البيئة.

    Detecting motion in rooms usually relies on cameras (privacy-sensitive) or dedicated sensors (coverage limited to line of sight). We explore an alternative based on wireless channel measurements.

    لوحتا ESP32 متوافقتان: مُرسِل ومُستقبِل. المستقبِل يستخرج قياسات CSI، وبايثون يعالجها، وخوارزمية تقدّر وجود حركة، ثم تُسجَّل النتيجة وتُعرض في لوحة تحكم.

    Two compatible ESP32 boards: a transmitter and a receiver. The receiver extracts CSI, Python processes it, an algorithm estimates motion, and the result is stored and shown on a dashboard.

    03 · How Wi-Fi CSI Works

    كيف يعمل Wi-Fi CSIHow Wi-Fi CSI Works

    اضغط على أي خطوة لرؤية ما يحدث. قد تتضمن CSI سعة وطور القناة حسب دعم العتاد والبرنامج الثابت.

    Select a step to see what happens. CSI may include channel amplitude and phase depending on hardware and firmware support.

    لماذا قد تتغير القياسات؟Why can measurements change?

    الموجات اللاسلكية تنعكس وتتشتت على الجدران والأثاث والأجسام. حركة جسم في مسار الإشارة قد تغيّر نمط التداخل، فيتغير CSI. لكن الأثاث والأبواب والتداخل اللاسلكي قد تسبب تغيّرات مماثلة، وهذا مصدر الإنذارات الكاذبة.

    Radio waves reflect and scatter off walls, furniture and bodies. A moving body in the signal path may change the interference pattern and therefore the CSI. Furniture, doors and wireless interference can cause similar changes — a source of false alarms.

    لماذا يهم توافق اللوحة والبرنامج الثابتWhy board and firmware compatibility matter

    10 · AI & Signal Processing

    الذكاء الاصطناعي ومعالجة الإشارةAI Algorithm and Signal Processing

    خط المعالجة الأساسيBaseline processing pipeline

    1. قراءة عينات CSI المزوّدة بطابع زمني.
    2. تحليل القياسات المتاحة.
    3. رفض العينات غير الصالحة.
    4. التطبيع أو الترشيح فقط عند وجود مبرر من الإشارة.
    5. حساب خصائص النوافذ.
    6. المقارنة مع خط أساس أو مصنِّف مدرَّب.
    7. تطبيق عتبة قرار موثقة.
    8. التنعيم/التأخير (Debounce) عند الحاجة.
    9. إرجاع حالة الحركة وثقة معايَرة اختيارية.
    1. Read timestamped CSI samples.
    2. Parse the available measurements.
    3. Reject invalid samples.
    4. Normalize or filter only when justified by the signal.
    5. Calculate window-based features.
    6. Compare with a baseline or trained classifier.
    7. Apply a documented decision threshold.
    8. Smooth or debounce predictions where appropriate.
    9. Return motion status and optional calibrated confidence.

    مقاييس التقييمEvaluation metrics

    • Recall = TP / (TP + FN): نسبة الحركة الحقيقية التي اكتُشفت.
    • Precision = TP / (TP + FP): نسبة الإنذارات الصحيحة.
    • معدل الإيجابيات الكاذبة على مستوى النوافذ = FP / (FP + TN).
    • زمن الاستجابة: من بدء الحركة إلى ظهورها في اللوحة.
    • Recall = TP / (TP + FN): share of real motion that was detected.
    • Precision = TP / (TP + FP): share of alarms that were correct.
    • Window-level false-positive rate = FP / (FP + TN).
    • Latency: from motion start to appearing on the dashboard.
    تسرّب المعلومات: النوافذ المتجاورة متشابهة جدًا (تتداخل). التقسيم العشوائي على مستوى الصفوف يضع نوافذ شبه متطابقة في التدريب والاختبار فتنتفخ الدقة. افصل بحسب جلسة التسجيل أو الغرفة/اليوم.Leakage: neighboring windows overlap and are nearly identical. A random row-level split puts near-duplicates in both train and test, inflating scores. Split by recording session (or room/day) instead.

    مثال تعليمي: تباين النافذة المنزلقة (NumPy)Educational example: sliding-window variance (NumPy)

    python — generic signal-processing demo
    import numpy as np

def sliding_window_variance(x, window=50, step=10):
    """Variance of each window of a 1-D signal.

    Generic signal-processing demonstration - NOT a complete
    Wi-Fi CSI algorithm.
    """
    x = np.asarray(x, dtype=float)
    if x.ndim != 1:
        raise ValueError("x must be 1-D")
    if window < 2 or window > len(x):
        raise ValueError("window must be in [2, len(x)]")
    starts = range(0, len(x) - window + 1, step)
    return np.array([np.var(x[s:s + window], ddof=1) for s in starts])

    جدول الأحداث (SQLite)Event table (SQLite)

    sql
    CREATE TABLE IF NOT EXISTS events (
  id              INTEGER PRIMARY KEY AUTOINCREMENT,
  room_id         TEXT    NOT NULL,
  motion_detected INTEGER NOT NULL CHECK (motion_detected IN (0, 1)),
  confidence      REAL    CHECK (confidence IS NULL OR (confidence BETWEEN 0 AND 1)),
  timestamp_utc   TEXT    NOT NULL,  -- ISO 8601, e.g. 2026-10-17T14:00:00Z
  source          TEXT    NOT NULL,  -- e.g. simulated_demo | esp32_live
  metadata        TEXT               -- optional JSON string
);
CREATE INDEX IF NOT EXISTS idx_events_room_time
  ON events (room_id, timestamp_utc);

    التحقق والأخطاءValidation and errors

    تحقق من الأنواع والنطاقات (الثقة 0–1)، وارفض الحقول المجهولة أو الناقصة برمز 4xx واضح، وأعد أخطاء منظمة. لا تعرض تفاصيل داخلية في رسائل الخطأ.

    Validate types and ranges (confidence 0–1), reject missing or unknown fields with a clear 4xx, and return structured errors. Do not leak internals in error messages.

    الطوابع الزمنيةTimestamps

    استخدم ISO 8601 بتوقيت UTC، وسجّل وقت الاستقبال إلى جانب وقت القياس عند الحاجة، وتعامل مع انحراف الساعة.

    Use ISO 8601 in UTC, optionally record receive time alongside measurement time, and account for clock drift.

    CORS والنشرCORS and deployment

    CORS يلزم فقط إذا كانت اللوحة على أصل مختلف عن الواجهة الخلفية؛ فعّله لأصول محددة لا للجميع. نقطة العرض التجريبي ليست نشرًا إنتاجيًا: الإنتاج يحتاج مصادقة وHTTPS وتحديد معدل ونسخًا احتياطيًا وسياسة احتفاظ بالبيانات.

    CORS is needed only if the dashboard is on a different origin than the backend; allow specific origins, not everyone. A demo endpoint is not a production deployment: production needs authentication, HTTPS, rate limiting, backups and a data-retention policy.
